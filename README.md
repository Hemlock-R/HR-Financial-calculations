# Financial Health & Wealth Dashboard 

A comprehensive, responsive web application designed for tracking personal finances, setting wealth goals, and monitoring daily financial velocity. Built entirely with vanilla web technologies, this tool operates directly in the browser with local storage.

 Core Features

*   **Real-Time Net Worth Tracking:** Instantly calculates total assets (including liquid cash) versus liabilities.
*   **Smart Item Classifier:** A rapid-entry categorization tool that automatically sorts inputs into Assets, Liabilities, Income, or Expenses based on custom keywords.
*   **Success & Goals System:** Allows users to set target net worth goals and tracks percentage completion with a visual progress bar.
*   **Daily Velocity Metrics:** Compares current financial standing against the most recently logged historical entry to show net worth gained or lost.
*   **Data Persistence:** Uses browser local storage to save real-time drafts and maintain a timestamped tracking history.
*   **Fully Responsive UI:** Optimized for all screen sizes, functioning flawlessly on both desktop environments and mobile devices.

## Technology Stack

*   **HTML5** 
*   **CSS3** (Custom properties, CSS Grid, Flexbox, Fluid Typography)
*   **JavaScript (ES6+)** (DOM manipulation, LocalStorage API)
